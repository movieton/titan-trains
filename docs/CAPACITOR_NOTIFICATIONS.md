# Фоновые напоминания через Capacitor

Браузерная PWA не может гарантированно показать локальное уведомление в 09:30, 11:30 или 20:00, если вкладка закрыта или Android выгрузил процесс. Notification Triggers в Chrome сняты, Periodic Background Sync для этого сценария не подходит. Пока Титан открыт, напоминание ставится таймером с окном в 5 минут. Когда приложение закрыто, рабочий путь — файл `titan-workout-schedule.ics` (кнопка в Настройках → Напоминания): календарь телефона сам покажет будильник.

Точные уведомления при закрытом приложении делаются нативной оболочкой, не сервисворкером.

## Что уже есть в коде

`src/utils/nativeReminders.ts`:

- На сайте `Capacitor` нет, функция сразу возвращает `{ mode: 'web' }` и ничего не обещает.
- Внутри Android-сборки она запрашивает разрешение, регистрирует действия «Начать» и «Отложить 10 мин» и ставит еженедельные Local Notifications по часам из настроек (`allowWhileIdle: true`).
- Тап «Начать» открывает `/?action=start_morning|start_break|start_kettlebell|start_walking`. Приложение читает `action` и запускает комплекс.
- «Отложить 10 мин» ставит одноразовое уведомление через 10 минут.

Часы берутся из профиля: зарядка 09:30, перерывы 11:30 / 13:00 / 14:30 / 16:00 / 17:30, вечер 20:00, пока пользователь их не изменил.

## Сборка APK

Нужны Node, Android Studio и JDK 17. Команды из корня репозитория:

```bash
npm install @capacitor/core @capacitor/cli @capacitor/local-notifications @capacitor/android
npm run build
npx cap add android
npx cap sync android
```

`capacitor.config.ts` уже указывает `appId` `com.lalo.titan` и `webDir` `dist`.

В `android/app/src/main/AndroidManifest.xml` для Android 13+ нужно разрешение `POST_NOTIFICATIONS`. Плагин Local Notifications добавляет его при sync. Точные будильники на Android 12+ зависят от разрешения SCHEDULE_EXACT_ALARM: на части прошивок его надо включить в системных настройках приложения, иначе сработает обычное окно, а не минута в минуту.

После правок веба:

```bash
npm run build && npx cap sync android
```

Проверка: поставьте напоминание на ближайшие 2 минуты, закройте приложение полностью, дождитесь уведомления, нажмите «Начать» и убедитесь, что открылся нужный комплекс.

TWA (Bubblewrap) сюда не подходит: это тот же сайт в оболочке Chrome, и расписание уведомлений она не добавляет.
